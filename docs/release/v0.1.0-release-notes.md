First public release. The package was extracted from the private HyperCarrier
repository, where it was `@hypercarrier/durable-compact`.

- Maps a working budget W onto pi-durable compaction (`workingBudget`,
  `compactTrigger`, `compactionSettings`). `./budget` has no imports.
- Writes a structured summary: the model's working-state summary, a Rarebit
  conversation record over the full durable history, and an index of dropped
  tool results. A failed model call falls back to native compaction and
  records why.
- Needs pi-durable 1.4.0 and `@hypercarrier/rarebit-durable` 0.1.0, both pinned
  exactly.

This version was published by hand and has no npm provenance. Later versions
publish from CI with provenance.
